Archrist WoW Addon

description
A versatile assistance addon for World of Warcraft: Wrath of the Lich King, covering group organization, utilities, crafting guides and personal notes.
technologies
[Lua][Ace3]
links
[repository] [distribution]

Built by studying established addons such as ElvUI, WeakAuras and Spy.

Features

  • Group organizer: sorts the group into tank, healer, melee and ranged roles
  • Cooldown tracker: important group spells in one frame
  • Loot filter: hides greed rolls from the chat
  • Posture check: periodic posture reminder
  • Crafting guides: profession leveling paths with estimated material costs

  • Guide maker: create and edit own guides

Experimental Data Mapping Projects

Published : Sun, 10 Nov 2019 Revision : Sun, 18 Oct 2026, v1.1 Language : English
description
Two data-mapping web projects from a media course: an interactive concept graph of Kittler's "The City as a Medium" and a filterable archive of 4000+ travelogue drawings (1420-1919).
technologies
[JavaScript][jQuery][Google Sheets][HTML/CSS]
links
[project I: article mapping] [project II: travelogues mapping]

Made in a media course on graph theory and information mapping (Fall 2019-20, led by Prof. Dr. Pelin Yoncaci Arslan). Both websites are still online.

Features

The City as a Medium

Friedrich Kittler’s 1996 article, mapped as an interactive graph.

  • Content split into headers, people, places, concepts, events, objects and analogies
  • Links between them drawn with the Alysii PI graph system, made for EVE Online

Travelogues archive

4000+ drawings by travelers (1420-1919) from the Aikaterini Laskaridis Foundation archive.

  • Drawings classified into 13 overlapping categories
  • Filter by year and follow production trends over time
  • Open any single drawing directly

Python Toolkit

Published : Sun, 17 Mar 2024 Revision : Sun, 18 Oct 2026, v1.1 Language : English
description
A collection of small Python tools that automate everyday tasks, from file management to image analysis and OCR.
technologies
[Python 3.11][Pillow][pytesseract][OpenCV (cv2)][NumPy]
links
[repository]

Each tool solves one specific need with a few options.

Features

Graph visualizer

Plots functions, e.g. to pick a timing curve for an animation.

  • Mathematical functions and two-parameter relations
  • Animation timing curves

File renamer

Bulk renaming for consistent file names.

  • Prefixes and suffixes
  • Upper or lower case names
  • Changed or overridden extensions

Image resizer

Prepares images for the web, thumbnails or storage.

  • Batch resizing
  • Aspect ratio kept

  • Color difference per pixel
  • Similarity percentage with highlighted differences

Text recognizer

Text recognition (OCR) for scanned documents.

  • Text from PDFs and images
  • Output as .txt or .md

OpenGL 3D Renderer

Published : Tue, 7 Nov 2023 Revision : Sun, 18 Oct 2026, v1.1 Language : English
description
An ongoing 3D renderer, a project to study computer graphics with custom linear algebra and modern OpenGL techniques.
technologies
[C++][OpenGL][imgui]
links
[repository]

The linear algebra behind it runs on self-written 4x4 matrix and vector libraries.

Features

  • Shapes from vertex data, textures and .obj model import
  • Perspective projection with own matrix and vector library
  • Movable camera and UI controls
  • Phong and Blinn-Phong lighting: directional, point and spot lights
  • Light maps and emission maps
  • Outline shader with depth and stencil testing
  • Transparency through blending, face culling
  • Frame buffers, uniform buffer objects
  • Cubemap skybox
  • GPU instancing
  • Anti-aliasing (MSAA)
  • Scene switcher and automated frame-based scene tests
  • Shadow mapping for point and directional lights
  • Normal and parallax mapping
  • HDR lighting with bloom
  • Deferred shading
  • Screen space ambient occlusion (SSAO)
  • Physically based rendering (PBR)

Study Projects

Published : Sat, 17 Oct 2026 Revision : Sun, 18 Oct 2026, v1 Language : English
description
Small repositories where I study one tool or topic at a time: build systems (CMake, xmake), backend deployment (Docker, Kubernetes, Terraform), machine learning (ML Lab) and algorithms (LeetCode).
technologies
[C++][CMake][xmake][Clang][Python][FastAPI][PostgreSQL][Docker][Kubernetes][Terraform][GitHub Actions][Jupyter][NumPy][Matplotlib]
links
[study-cmake] [study-xmake] [study-cloud] [study-leetcode] [ml-lab]

Each repository is built in steps that add one concept at a time, before the tool goes into a larger project.

Features

CMake

A C++ project to learn the CMake build system generator.

  • Visual Studio 2022 solution generated by CMake, also through .bat scripts
  • GLFW and Assimp built from source as subdirectories
  • Own static library hello linked into the program
  • OpenGL linked through find_package

xmake

study-cmake rebuilt with xmake and Clang on Windows (MSYS2 CLANG64), one concept per step.

  • Single program: target, add_files
  • Source and header folders: add_includedirs
  • Static library: set_kind("static"), add_deps
  • Defines, debug / release modes and output folder
  • Packages instead of submodules: GLFW, Assimp, glad, imgui

Cloud deployment

A small FastAPI service, taken step by step through Docker, Kubernetes and Terraform.

  • FastAPI app with a health check, a notes API and tests
  • Docker image, Compose with PostgreSQL, data in a volume
  • Tests and image build on every push (GitHub Actions)
  • Local Kubernetes cluster (kind) with storage and health probes
  • Terraform: local Docker provider first, then AWS (ECR, EC2 or ECS)

ML Lab

A learning lab for machine learning and LLMs, organized as a personal curriculum in Jupyter notebooks.

  • Foundations: Jupyter, NumPy and Matplotlib
  • Linear regression
  • Logistic regression
  • Reusable data generators and models extracted from the notebooks
  • Transformer internals and LLM fine-tuning

LeetCode

Data structures and algorithms on LeetCode problems, solved in Python. To be written in detail.

  • Problems solved in Python, each runnable with its own test cases
  • Own data structures: binary tree, n-ary tree, linked list, stack
  • Problem categories and notable solutions
